# ISL Translator — Real-Time Indian Sign Language Recognition

A real-time computer vision system that translates Indian Sign Language (ISL) gestures into text and speech, with a 3D avatar for bidirectional communication.

## 🛠️ Tech Stack

- **Computer Vision:** MediaPipe Holistic
- **AI/ML:** BiLSTM, TensorFlow
- **Cloud:** AWS SageMaker, S3, Polly
- **3D Animation:** Unity
- **Backend:** Flask, WebRTC
